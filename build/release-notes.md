## GRAŃ 1.0.0 – pierwsze wydanie aplikacji desktopowej

Atlas szlaków górskich 3D jako samodzielny program dla Windows (zamiast strony WWW).

- **Instalator** z wyborem folderu (domyślnie `Program Files`), skrótami na pulpicie i w menu Start oraz pełną deinstalacją z Panelu sterowania.
- **Pierwsze uruchomienie**: wybór przechowywania danych – zachowywanie kafli i danych okolic z **limitem pojemności** (1–500 GB, najdawniej używane usuwane automatycznie) albo **usuwanie przy każdym zamknięciu** programu. Zmiana w zakładce „Jakość” → „Dane i pamięć” lub skrótem `Ctrl+,`.
- Interfejs i wszystkie funkcje jak w wersji przeglądarkowej: teren LiDAR, szlaki, trasy z wariantami, wysokość względna, widoczność, cienie, przeloty, GPX.
- Lokalny serwer danych działa wyłącznie na `127.0.0.1`; fonty dołączone do programu (bez zależności od Google Fonts).
- **Automatyczne aktualizacje** z GitHub Releases.

Skróty okna: `F11` pełny ekran, `Ctrl` + `+`/`-`/`0` powiększenie interfejsu, `Ctrl+R` odświeżenie widoku.
